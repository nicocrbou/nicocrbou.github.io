## This website

KIWI-biolab.org is a static information website about the KIWI Biolab and the original KIWI-biolab Future Lab project. For enquiries about the website, contact the department office at **office[at]bioprocess.tu-berlin.de**.

## Hosting

This website is hosted on GitHub Pages. Requests to the hosting provider include technical information needed to deliver pages, such as an IP address. GitHub describes its processing of personal information in the [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Cookies, analytics and local features

The website does not set cookies, use analytics, create accounts or accept form submissions. Search and filtering run in your browser against content already included in the page. Search terms may appear in the address bar and browser history; the site does not send them to a search service or store them in local storage.

Fonts and website images are served with the site. No third-party video, map or social-media widget is loaded automatically.

## External websites

Links to institutional pages, publications, LinkedIn and the virtual lab tour open external websites. Those services apply their own privacy policies. The external tour is a link, not an embedded service.

## Email

Email addresses are displayed as plain text with `[at]`. Contacting the department by email takes place through your email provider and the recipient's email system, outside this website. Do not submit personal information through GitHub issues or other public repository features.

## Further information

For institutional data-protection information, see [TU Berlin’s data-protection page](https://www.tu.berlin/en/data-protection). For questions about information on this website, use the details on the [Contact page](/contact/).
